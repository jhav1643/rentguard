classifier-service has been deployed to namespace {{ .Release.Namespace }} as a Job.

Check Job status:
  kubectl get jobs -n {{ .Release.Namespace }} -l app.kubernetes.io/name={{ include "chart.name" . }}

Watch the training pipeline:
  kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/name={{ include "chart.name" . }} -w

Read the logs (shows data_prep → train → evaluate stages):
  kubectl logs -n {{ .Release.Namespace }} -l app.kubernetes.io/name={{ include "chart.name" . }} --tail=100

Expected pod states:
  Running   → pipeline in progress (can take several minutes)
  Completed → all three stages finished successfully
  Error     → pipeline failed; check logs above

Re-run the pipeline:
  helm upgrade classifier-service ./infra/helm/classifier-service -n {{ .Release.Namespace }} \
    --set image.repository=<YOUR_ECR_REPO_URI>/classifier-service --set image.tag={{ .Values.image.tag }}

The env Secret ({{ .Values.envSecretName }}) must exist BEFORE install:
  kubectl create secret generic {{ .Values.envSecretName }} \
    --namespace {{ .Release.Namespace }} --from-env-file=.env
